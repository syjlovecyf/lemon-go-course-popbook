# 一堂好课，是怎样磨出来的

以纸艺方式演绎柠檬说棋备课过程，不作为真实工作现场纪录。人物、手写教案、摆棋、试讲与学生反馈为主角。

参考片为 1920×1080、30 fps、38.2 秒。视觉语法是暖棕桌面、米白纸张、墨绿书脊、粗宋体纸条字幕、彩色标签。前六秒开书；随后背景立起，折页与小道具逐个弹出；后段拉远、合书与收束。新作重新绘制全部图形，不包含参考视频。

本片采用连续立体书舞台，六段叙事：封面、翻资料、摆棋验证、写教案、试讲修改、课堂展开。确定性 SVG 和帧动画实现纸景、人物、手部、铅笔及折页。棋盘共享十九路坐标，星位为第 4、10、16 路；局面为示意。

实施顺序：建立工程和 Studio；绘制和动画；固定音色录制；TypeScript 与棋盘结构检查；抽帧和完整渲染；仓库敏感内容检查；公开推送；核验远端提交和 REST 绑定。

验收：可用 npm ci 还原，npm run check 和 npm test 通过；实际 MP4 的画面、时长和音轨正确；公开仓库与本地提交一致；绑定响应的片段 ID 和仓库根地址匹配。私人音色档案、签名源地址和凭证永不进入公开源码。
